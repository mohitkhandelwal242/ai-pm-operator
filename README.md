# ✦ AI-PM Operator

You have successfully installed the **AI-PM Operator**! This is a production-grade AI operations toolkit that connects to your company's real tools (Jira, Google Analytics, GSC, mobile stores) and gives you an autonomous co-pilot directly inside Claude Code.

---

## 🚀 Quick Start

### 1. Run the Onboarding Wizard
If it didn't launch automatically, run:
```bash
python3 tools/setup-wizard.py
```
This script will:
- Validate your license key.
- Connect to your Jira Cloud project.
- Gather your team roster details and create `team.json`.
- Write your `.env` configuration.

### 2. Launch Claude Code
Run the Claude CLI in this repository root:
```bash
claude
```

### 3. Run Your First Workflow
Try calling one of the core skills:
- Ask Claude: `Run daily scrum master sweep` or `/scrum` (audits Kanban health, flags stale/blocked issues).
- Ask Claude: `Generate a weekly plan` or `/weekly-plan` (compiles sprint plans based on capacity).
- Ask Claude: `Write a PRD for [feature]` or `/prd-generator` (drafts complete spec docs).

## 🔒 Security & Data Privacy

- **Local First**: All API keys, credentials, and configuration files (`.env`, `team.json`) remain strictly on your local machine and are never transmitted to any third-party server besides your direct tool endpoints (Atlassian Jira, Google API, etc.).
- **GDPR & HIPAA Compliance**: We do not store, intercept, or train models on your proprietary company data.
- **Git Safeguards**: The installer automatically updates your `.gitignore` file to ensure `.env` and `team.json` are never committed to your code repositories.
